# URL Shortener на Go

Легковесный HTTP-сервис для сокращения длинных URL-адресов с хранением данных в памяти и полным покрытием unit- и интеграционными тестами.

## Структура проекта

```text
urlshortener/
├── go.mod            # Описание модуля Go
├── main.go           # HTTP-сервер, маршрутизация и обработчики запросов
├── shortener.go      # Потокобезопасная бизнес-логика сокращения и валидации URL
├── shortener_test.go # Table-driven unit-тесты для бизнес-логики
└── handlers_test.go  # Тесты HTTP-эндпоинтов с использованием net/http/httptest
```

## Запуск сервера

Запустить приложение локально на порту `:8080`:

```bash
go run .
```

## API Эндпоинты (шпаргалка по запросам)

### 1. Создание короткой ссылки (`POST /shorten`)

Принимает JSON с оригинальным адресом (`http` или `https`) и возвращает сгенерированный идентификатор длиной 6 символов.

**Пример запроса (`curl`):**
```bash
curl -i -X POST http://localhost:8080/shorten \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'
```

**Пример ответа (`201 Created`):**
```json
{
  "short_url": "aB3x9Z",
  "original_url": "https://example.com"
}
```

**Возможные ошибки:**
* `400 Bad Request` — некорректный JSON или невалидный URL (отсутствует схема `http`/`https` или домен).
* `405 Method Not Allowed` — использован HTTP-метод, отличный от `POST`.

---

### 2. Переход по короткой ссылке (`GET /{short_url}`)

Выполняет перенаправление на исходный URL по короткому идентификатору.

**Пример запроса (`curl`):**
```bash
curl -i http://localhost:8080/aB3x9Z
```

**Пример ответа (`302 Found`):**
```http
HTTP/1.1 302 Found
Location: https://example.com
```

**Возможные ошибки:**
* `404 Not Found` — короткий идентификатор не найден или не передан.
* `405 Method Not Allowed` — использован HTTP-метод, отличный от `GET`.

---

## Тестирование и покрытие (шпаргалка по командам)

* **Запуск всех тестов с подробным логом:**
  ```bash
  go test -v ./...
  ```

* **Проверка процента покрытия тестами:**
  ```bash
  go test -cover ./...
  ```

* **Проверка на состояние гонки (race condition) при многопоточной работе:**
  ```bash
  go test -race ./...
  ```

* **Визуальный отчет о покрытии в браузере (зеленым — покрыто, красным — нет):**
  ```bash
  go test -coverprofile=coverage.out && go tool cover -html=coverage.out
  ```
  *(Не забудьте удалить временный файл `coverage.out` после просмотра: `rm coverage.out`)*
